# fan-biz-insights 콘텐츠 저장소

이 리포지토리는 fan-biz-insights 프로젝트의 **articles**와 **scripts**를 백업하는 private 저장소입니다.

## 📁 구조

```
.
├── articles/           # 모든 글 (마크다운 파일 + 이미지)
├── scripts/            # 업로드 및 관리 스크립트
└── README.md
```

## 🔒 보안

이 리포지토리는 **Private**으로 설정되어 있으며, 다음 정보는 포함되지 않습니다:
- `.env` 파일 (환경 변수)
- API 키 및 시크릿
- Supabase Service Role Key

## 📝 사용법

이 리포지토리는 자동 백업 스크립트에 의해 관리됩니다.
- 글 수정 시 자동으로 커밋 & 푸시됩니다
- 버전 관리를 통해 이전 버전 복구 가능
